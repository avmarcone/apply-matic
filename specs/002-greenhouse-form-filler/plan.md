# Implementation Plan: Greenhouse Form Filler

**Branch**: `002-greenhouse-form-filler` | **Date**: 2026-05-18 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-greenhouse-form-filler/spec.md`

## Summary

Build `src/greenhouse.ts` — a Playwright-based module that opens a Greenhouse job
application URL in a headed browser, fills all detectable standard fields from the
user's profile, detects open-ended questions for Claude to answer, and returns the
live page for human review. The orchestrator in `src/index.ts` is updated to call
`fillForm` instead of the stub `processJob`.

## Technical Context

**Language/Version**: TypeScript 6 / Node.js 22+

**Primary Dependencies**:
- `playwright` — browser automation (already installed)
- Types from `src/types.ts` (spec 001)

**No new runtime dependencies required.**

**Storage**: N/A — stateless; reads profile fields, writes to DOM

**Testing**: Vitest unit tests for selector logic and field mapping; Playwright
integration tests are out of scope for v1 (require a live Greenhouse page)

**Target Platform**: macOS local, headed Chromium (display required)

**Project Type**: CLI tool module

**Performance Goals**: Standard field filling completes in under 30 seconds (SC-005)

**Constraints**: No headless mode; no auto-submit; browser stays open after filling
